# Drop your intro video here

Drag and drop **one** of these into this folder:

- `open-limits-intro.mp4` — the final MP4
- `open-limits-intro.mp4.zip` — a ZIP containing the MP4

After you drop the file, tell the agent:

> Use the file in uploads/intro-video/

The agent will install it to `public/intro-video/open-limits-intro.mp4`, verify it is not the 489 KB placeholder, and recreate the project backup.

**Do not commit large video files unless you intend to store them in git.**
